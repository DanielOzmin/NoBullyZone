# NoBullyZone 🙅‍♂️

**NoBullyZone** is a social media platform created to reduce and prevent cyberbullying. The project's goal is to build a positive, supportive, and constructive online space—using Ai and algorithm-based moderation to filter harmful content, while encouraging positive feedback and thoughtful, constructive criticism that strengthens the community.

---

## 🔧 Technologies

### Frontend
- [React](https://reactjs.org/)
- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

### Backend
- [ASP.NET Core](https://learn.microsoft.com/en-us/aspnet/core/)
- [C#](https://learn.microsoft.com/en-us/dotnet/csharp/)
- [Entity Framework Core](https://learn.microsoft.com/en-us/ef/core/) (ORM)
- [SignalR](https://learn.microsoft.com/en-us/aspnet/core/signalr/introduction) – for real-time chat functionality

### Database
- Microsoft SQL Server (MSSQL)

### External Services
- [Amazon S3 (AWS)](https://aws.amazon.com/s3/) – for image and video storage

## 🎯 Features (current status)

- 🔐 User registration and login
- 🔄 Authentication & Authorization (JWT)
- 🧭 Navigation: base structure with Navbar and Sidebar
- 👥 User search and friends list
- 👤 Personal profile page (basic structure, under development)
- 📊 Statistics view (UI template present, backend logic in progress)
- 🖼️ Gallery module: create image/video albums and upload content
- 🚪 Logout functionality

---

## 🧠 Philosophy & Principles

- Built following the **SOLID** and **OOP** (Object-Oriented Programming) principles.
- The system uses AI and rule-based algorithms to **detect toxic behavior** and **promote constructive, kind interaction**.
